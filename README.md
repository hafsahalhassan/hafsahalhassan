#### 💱 [Forecasting Exchange Rates with AI](https://github.com/hafsahalhassan344-ops/exchange-rate-forecasting-ai)
**Can ChatGPT-style tools beat simple models at forecasting currencies?**

I collected real-time forecasts from **Copilot** and **Gemini** for 5 currencies over 6 horizons and tested them against random-walk and AR(1) benchmarks.

**Finding:** prompting with the latest rate sharply cut errors, but neither AI tool consistently beat the simple benchmarks.
